How It Works

Deposit, shield, withdraw — privacy in three steps

1

Deposit

Send ETH to the AEGIS Shield contract. Your funds enter the privacy pool and are no longer publicly traceable to you.

2

Generate Proof

Create a zero-knowledge proof that confirms ownership of deposited funds without revealing your private key or deposit history.

3

Withdraw

Transfer funds to any address. On-chain records only show movement from the pool, not your original deposit.

Get Started

Integrate AEGIS into your project

SDK Installation

# Install the SDK
npm install @aegis/sdk

# Connect and deposit
import { AegisShield } from '@aegis/sdk';

const aegis = new AegisShield(provider);
await aegis.deposit({ amount: '0.1' });

Smart Contract Integration

// Import AEGIS Shield
import "@aegis/protocol/contracts/AegisShield.sol";

contract MyContract {
    AegisShield public shield;
    
    function deposit() external payable {
        shield.deposit{value: msg.value}(
            keccak256(abi.encodePacked(
                msg.sender, msg.value, block.timestamp
            ))
        );
    }
}
