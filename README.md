# AEGIS — Programmable Privacy Infrastructure

🛡️ Privacy layer for Base blockchain using zero-knowledge proofs.

## Features

- Encrypted transfers with ZK proofs
- Agent-compatible privacy shielding
- On-chain activity masking

## Getting Started

Live demo: [aegis-dkp.netlify.app](https://aegis-dkp.netlify.app)

### Development

```bash
# Clone
git clone https://github.com/aegis37/aegis-protocol.git
cd aegis-protocol

# Frontend
open frontend/index.html  # or run local server
```
